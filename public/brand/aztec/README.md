# Aztec marks

These files were added as Aztec's marks in commit 7e4ab8b (brand kit), as vector SVG:

- `aztec-wordmark-ink.svg`: the wordmark, ink, for white backgrounds;
- `aztec-wordmark-paper.svg`: the wordmark, paper, for dark backgrounds;
- `aztec-symbol-ink.svg`, `aztec-symbol-paper.svg`, `aztec-symbol.svg`: the symbol.

The landing shows the ink wordmark ("Built on Aztec Network") from `lib/landing/content.ts` → `BRAND_FILES`.
