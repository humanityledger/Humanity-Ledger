# Humanity Ledger — Responsible Disclosure Policy
#
# We take security seriously. If you discover a vulnerability:
#
# 1. Email security@humanidfi.com with a clear description
# 2. Include: affected component, steps to reproduce, impact assessment
# 3. Do NOT publicly disclose until we've had 90 days to fix
# 4. We will acknowledge receipt within 48 hours
# 5. We will provide a fix timeline within 7 business days
#
# Scope: auth, messaging, payments, communities, API routes, smart contracts
# Out of scope: social engineering, physical attacks, DoS/DDoS
#
# We currently do not offer monetary bug bounties, but we will:
# - Credit you in our security acknowledgements (if desired)
# - Provide a letter of recognition
