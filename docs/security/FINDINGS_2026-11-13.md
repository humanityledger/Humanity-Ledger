# Repository security sweep, 13 November 2026

Scope: `app/`, `lib/`, `components/`, `middleware.ts`, configuration, dependencies. Searched for simulated or
fabricated values, `Math.random` in sensitive code, keys in browser storage, secrets in logs or public variables,
type-check suppressions, stale audit documents, and missing environment documentation. Base: `main` at `68f3659`.

| F-01 | Critical | `lib/xmtp/client.ts:244-260` | The XMTP local database key is random and stored **in plaintext in `localStorage`** (`ledger_xmtp_db_key_<address>`). Any script running on the origin (an XSS, a compromised dependency) can read it and decrypt the local message database. | **Fixed** (`lib/xmtp/db-key.ts`): keys derived from a wallet signature (HKDF), held in memory for the tab; existing databases keep their key, now AES-GCM-encrypted with a signature-derived key and the plaintext deleted, so no history or installation is lost; a different signature is refused instead of creating a second database. Test: `test/unit/security/xmtp-db-key.test.ts`. |
