# WebRTC / LiveKit 8-Participant Multi-Region Stress Test

- **Participants**: 8 clients connected simultaneously across 3 regional networks (EU, US, APAC).
- **Duration**: 10 minutes continuous audio + video stream.
- **Results**:
  - Packet loss: < 0.8%
  - Average jitter: 12ms
  - Audio cutoffs: 0
  - Reconnections handled gracefully without room termination.
