# Law Enforcement Response Policy

**Last updated**: October 2025

---

## Our Commitment

We are committed to user privacy. We will not share user data with law enforcement unless legally compelled to do so by a valid legal process.

---

## What We Can Provide

Due to our privacy-first architecture, there is very little data we can provide even if legally compelled:

| Data | Available? | Notes |
|------|-----------|-------|
| Wallet address | Yes (if account exists) | Pseudonymous — not tied to real identity |
| Email address | Yes (if user provided one) | |
| Registration timestamp | Yes | |
| Last login timestamp | Yes | |
| IP addresses | Yes (from logs, ≤ 30 days) | |
| Message content (DMs) | **No** | End-to-end encrypted via XMTP — we cannot decrypt |
| Private payment amounts | **No** | ZK-private — we store only txHash |
| Private community messages | **No** | XMTP MLS — we cannot decrypt |
| Public community posts | Yes | Server-stored, unencrypted |

---

## Process

1. All requests must be submitted to: **legal@humanityledger.com**
2. We require a valid legal process (court order, subpoena, warrant) from the appropriate jurisdiction
3. We will notify the affected user **unless prohibited by law** (e.g., gag order)
4. Emergency requests (imminent threat to life) are evaluated expeditiously
5. We reserve the right to challenge overly broad or legally deficient requests

---

## Transparency Report

We aim to publish an annual transparency report disclosing:
- Number of requests received (by jurisdiction)
- Number of requests complied with
- Data types provided (in aggregate)

---

## Contact

**Legal requests**: legal@humanityledger.com  
**Response time**: 10 business days (non-emergency)
